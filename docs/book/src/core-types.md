# Core Types

`tpt-yard-core` defines what is being built and the primitives every other
crate shares.

## `VesselProject`

A [`VesselProject`](tpt_yard_core::VesselProject) is the complete build plan:
which vessel, which construction method, and the ordered
[`BuildPhase`](tpt_yard_core::BuildPhase)s with their
[`AssemblyActivity`](tpt_yard_core::AssemblyActivity) networks.

```rust
use tpt_yard_core::*;

let mut phase = BuildPhase::new(PhaseId(1), "Erection", 10.0);
phase.activities.push(AssemblyActivity::new(
    ActivityId(1),
    "Erect block 212",
    ActivityType::JoinBlock,
    8.0,
));
let project = VesselProject::new(
    ProjectId(1),
    "Container ship 14k TEU",
    VesselType::Sea(SeaVesselType::ContainerShip { teu_capacity: 14_000 }),
    ConstructionMethod::SeaDrydock,
    vec![phase],
).unwrap();
```

Vessel taxonomy mirrors the two worlds:

- `VesselType::Sea(SeaVesselType)` — container ships, tankers, LNG carriers,
  cruise ships, naval vessels, submarines (single/double hull), offshore and
  fishing vessels.
- `VesselType::Space(SpaceVesselType)` — stations, rotating habitats, solar
  power stations, deep-space vessels, lunar/Mars vehicles, orbital factories,
  fuel depots.
- `VesselType::Hybrid` — e.g. a space-rated pressure hull tested at sea.

Construction methods: `SeaBlockConstruction`, `SeaSlipwayLaunch`,
`SeaDrydock`, `OrbitalAssembly`, `InSpaceManufacturing`,
`LunarSurfaceConstruction`.

## Activities

An `AssemblyActivity` is a unit of work with a type (`ActivityType`:
`CutSteel`, `WeldBlock`, `LiftBlock`, `JoinBlock`, `Outfit { system }`,
`RoboticAssembly { robot }`, `AdditiveManufacturing { material }`, ...),
a duration, dependencies, and the yard `Resource`s it consumes. The
dependency network is validated with `VesselProject::activity_graph()`,
which reuses the algorithms of `tpt-yard-assembly` (topological order, cycle
detection, CPM forward pass).

## Geometry primitives

- [`Vector3`](tpt_yard_core::Vector3) — metres, with the usual operations.
- [`Geometry3D`](tpt_yard_core::Geometry3D) — a triangle mesh
  (`from_box`, `from_cylinder`, `translate`, `rotate_z`, `bounding_box`,
  `centroid`, `merge`) used for block and outfit geometry and for WASM
  rendering.
- [`MassProperties`](tpt_yard_core::MassProperties) — `(mass, CoG)` with
  weighted combination.

## Identifiers

`ProjectId`, `PhaseId`, `ItemId`, `BlockId`, `RobotId`, `ComponentId`,
`StepId`, `WeldId` — copyable newtypes over `u64` generated by the exported
`define_id!` macro, serializing as JSON numbers.

## JSON

The crate embeds a dependency-free JSON implementation
([`tpt_yard_core::json`]) so projects round-trip without pulling in external
crates — part of the pure-Rust, MIT-only-chain design:

```rust,ignore
let json = project.to_json().to_string_pretty();
let same = VesselProject::from_json_str(&json).unwrap();
assert_eq!(same, project);
```

`VesselProject::from_json(path)` loads from a file (the Quick Start in the
README uses exactly this).
