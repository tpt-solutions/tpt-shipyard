# Rotating habitat construction

> The full rotating-habitat design chain for a Stanford torus and an O'Neill cylinder: spin rate, Coriolis comfort, thermal-fatigue life, structural sizing, and Whipple-shield screening.

**Run it:**

```bash
cargo run -p rotating-habitat-construction
```

**Expected output:** Spin-rate/comfort tables for 1 g and Mars g, shell sizing, and 15-year thermal-cycling life fractions.

This example is part of the [tpt-shipyard](https://github.com/tpt-solutions/tpt-shipyard)
workspace (Phase 4). It is a workspace-only package (`publish = false`) — the
publishable crates live under `crates/`.
